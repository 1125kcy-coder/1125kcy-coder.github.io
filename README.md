# Chae Yeon Kim Academic Portfolio

This folder is ready for GitHub Pages.

## Upload target

Upload every file and folder inside this package to:

`1125kcy-coder/1125kcy-coder.github.io`

The repository root should contain:

- `index.html`
- `assets/`
- `projects/`
- `README.md`

## Replace the two placeholders

1. Replace `assets/img/profile-placeholder.svg` with your real profile image.
   - Recommended name: `profile.jpg`
   - Then change the image path in `index.html` from:
     `assets/img/profile-placeholder.svg`
     to:
     `assets/img/profile.jpg`

2. Replace `assets/docs/Chaeyeon_Kim_CV.pdf` with your actual CV PDF.
   - Keep the same filename so the button link keeps working.

## GitHub Pages

Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`

Public URL:

`https://1125kcy-coder.github.io/`
