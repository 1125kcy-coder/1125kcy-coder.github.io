Project Background

Daily media-monitoring tasks required repetitive collection, sorting, classification, duplicate checking, and weekly-summary preparation. This project explored how those recurring steps could be automated while preserving researcher review and judgment.

02

Workflow

Article collection → Cleaning and sorting → Category classification → Duplicate detection → Weekly-summary preparation → Researcher review

Documentation
